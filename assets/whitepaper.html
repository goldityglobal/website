GOLDITY Whitepaper

GOLDITY (GDTY) is a fixed-supply digital asset deployed on BNB Smart Chain. This document describes the currently verified token parameters, contract behavior, market-data methodology and account/referral framework.

1. Token Overview

Name: GOLDITY
Symbol: GDTY
Network: BNB Smart Chain
Chain ID: 56
Decimals: 18
Total supply: 19,100,000 GDTY

2. Contract

The official GDTY contract address is shown on the dedicated Contract page and should always be verified before interacting with the token.

View Contract →

3. Contract Mechanics

The current contract uses a fixed supply with no mint function. Holders can burn their own tokens. Buy tax is 0%; sell tax is 0%; wallet-to-wallet transfers are 0%. The contract uses two-step ownership and supports tax-exempt pair/vesting addresses according to its deployed logic.

4. Market Reference Price

The website's Reference Price is calculated from valid GDTY/USDT prices from the configured Uniswap V2 and PancakeSwap V2 pools. When both configured sources are valid, the Reference Price is their arithmetic mean. If one source is unavailable, the site does not present a two-source average and displays the reference price as unavailable until both sources are valid again.

5. Accounts & Referral Codes

Registered users receive a unique referral code. A new registration may include an existing code, creating referral attribution. For eligible verified GDTY purchases made on supported external DEX markets, the referral program may record an internal reward equal to 5% of the eligible GDTY purchase amount for the referring account. This referral reward is an internal website accounting mechanism and is not a token buy tax, sell tax or wallet-to-wallet transfer tax.

6. Privacy & Compliance

Personal data is processed according to the site's Privacy Notice. The service should use purpose limitation, data minimisation, retention controls, security safeguards and transparent notices.
